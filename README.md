([u-azazex-last-text-at-one-percent-ba9fc876](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876)).

## The entry

`main.py` writes the last text message a phone sends at one percent
battery to `/output/entry.txt`: a tiny will from the dying phone itself —
the charger inherits nothing, one confession, and a final favour.
Deterministic, Python 3 standard library only, no network, no input, no
randomness.

## Run it

```sh
python3 main.py
```

It writes exactly one fixed line (under the 200-character limit) to
`/output/entry.txt`. Set `ENTRY_OUTPUT` to write elsewhere when testing
locally.
